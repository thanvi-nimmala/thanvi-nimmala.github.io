# thanvi-nimmala.github.io

Portfolio of Thanvi Nimmala — product designer.

Plain static site: no build step, no dependencies. `index.html` holds the landing
and the four case studies; the behaviour is split across small scripts
(`showcase.js` for the landing, `pin.js`, `reveal.js`, `motion.js`, `intro.js`).

Run locally with any static server, e.g. `python3 -m http.server`.
